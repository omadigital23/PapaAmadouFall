# OMA Digital Automation Portfolio

## Purpose

Show how practical automation can help small businesses capture leads, qualify prospects, and respond faster.

## Relevant Project Types

- Lead capture workflow
- WhatsApp or Telegram handoff
- CRM update automation
- Email notification workflow
- AI-assisted lead qualification
- Website form to database workflow

## Infrastructure Proof

Self-hosted n8n on a cloud VM using Nginx as a reverse proxy, configured DNS for n8n.omadigital.net, enabled HTTPS access, and routed external traffic securely to the internal n8n service.

- Self-hosted n8n on a cloud VM
- Nginx configured as a reverse proxy
- DNS configured for n8n.omadigital.net
- HTTPS access enabled for secure browser traffic
- External traffic routed securely to the internal n8n service

## Skills Demonstrated

- API thinking
- n8n workflow design
- Nginx reverse proxy, DNS, and HTTPS setup
- Business process mapping
- Customer communication
- Practical automation for small businesses

## Portfolio Value

This project supports the transition from support technician to automation-focused technical roles. It also shows business understanding, not only coding.
