# Technical Support Knowledge Base

## Purpose

Build a practical support knowledge base that demonstrates real troubleshooting logic for Windows users, Microsoft 365 access, Teams/OneDrive basics, workstation setup, peripheral issues, internet connectivity, modem/router issues, Wi-Fi performance, DNS basics, telephony service issues, and customer communication.

## Target Audience

- IT support recruiters
- Help desk managers
- Client support analyst hiring teams
- SaaS support teams
- Telecom support teams

## Skills Demonstrated

- Clear technical documentation
- Step-by-step troubleshooting
- Customer-friendly explanations
- Microsoft 365 and Windows user support readiness
- Peripheral and workstation support logic
- Escalation judgment
- Bilingual support readiness

## Suggested Sections

- Internet connection down
- Slow Wi-Fi troubleshooting
- Modem/router restart and validation
- Windows sign-in and workstation setup checks
- Microsoft 365, Teams, OneDrive, and SharePoint user support notes
- Printer, phone, scanner, webcam, and mobile device checks
- DNS issue checklist
- Device-specific troubleshooting: Windows, macOS, Android, iOS
- When to escalate to level 2
- Customer response templates in English and French

## Portfolio Value

This project supports the `Client Support Analyst` and `User Support Technician` profile by proving that the candidate can explain technical issues clearly, document helpdesk actions, and follow structured support procedures.
